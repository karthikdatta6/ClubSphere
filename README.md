
# ClubSphere 🌐

ClubSphere is a multi-club management platform designed for educational and co-curricular communities worldwide.

## 🎯 Project Objective

Enable clubs across different locations to register, manage their members, and maintain their own independent member directories on a single platform.

## ✨ Planned Features

- Register multiple clubs worldwide
- Support educational, music, dance, arts, and sports clubs
- Search and discover clubs by category and location
- Verify club eligibility and approve registrations
- Register members and manage membership requests
- Add, view, search, update, and remove member records
- Provide separate access for platform administrators, club administrators, and members
- Keep each club's data separate and secure

## 🛠️ Technology Stack

- **Frontend:** React, JavaScript, CSS, Vite
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Security:** Spring Security
- **Version Control:** Git and GitHub
